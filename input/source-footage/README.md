# Source footage drop folder

Put approved GTA video clips or images here before creating a Short.

Accepted video files: `.mp4`, `.mov`, `.mkv`, `.webm`  
Accepted image files: `.png`, `.jpg`, `.jpeg`

Use footage you own or have permission to reuse. The renderer will build an edited vertical Short from these assets instead of using static graphic cards.

## Older games
Drop your own gameplay recordings (vertical or landscape .mp4) into `gta1/`, `gta2/`, `gta3/`, `gta4/`, `gta5/` and `rdr2/`.
Any Short whose script mentions that game uses those clips first, then fills with GTA VI trailer cuts.
